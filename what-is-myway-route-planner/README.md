# What is MyWay Route Planner?

{% hint style="info" %}
**Using MyWay on Android?** This page describes the iOS app version 3. See [Version 2 of this page](https://help.mywayroute.com/what-is-myway-route-planner).
{% endhint %}

**MyWay Route Planner** **builds the most efficient routes**. It puts the stops of your route in the best order, so you save time and money on fuel.

MyWay is built for delivery drivers, sales reps and everyone who needs to visit multiple stops during the day. Instead of planning a route by hand, you add your stops, and MyWay plans a route with multiple locations in seconds and keeps your mileage low.

We use the best technologies on the market. MyWay builds routes based on traffic conditions, with the most up-to-date maps, addresses and places databases from Google Maps, Mapbox, HERE, TomTom, Apple Maps, ArcGIS and OpenStreetMap combined into a single route planner.

If you used the previous version of MyWay, see [what's new in MyWay 3](whats-new-in-myway-3.md).

To learn more, visit our website: [https://mywayroute.com](https://mywayroute.com)
